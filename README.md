# Project Management System (Web)

Web Technologies semester project: a small Node.js app (`server.js`, `app.js`, `index.html`, `style.css`).

```bash
git clone https://github.com/hamza2324/Project-Management-System-web-.git
cd Project-Management-System-web-
npm install
node server.js
```

Confirm the listen port in `server.js` after clone. Academic prototype — not a production PM tool.
